O **Super Jogo da Palavra Secreta** é uma aplicação interativa desenvolvida para praticar lógica de programação, manipulação de Arrays (Vetores) e estruturas condicionais em JavaScript.

## 🚀 Como funciona?
O objetivo é descobrir a palavra oculta ("TRICOLOR") testando uma letra por vez. O sistema gerencia as letras restantes e atualiza o progresso em tempo real.

- **Confira o Tamanho:** O jogo inicia informando quantos caracteres a palavra possui.
- **Chute uma Letra:** O sistema aceita letras maiúsculas e minúsculas.
- **Feedback Visual:** O painel exibe `- - -` para letras ocultas e revela a letra na posição correta ao acertar.
- **Vitória:** O desafio termina quando o contador de caracteres restantes chega a zero.

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estruturação da página.
- **CSS3**: Estilização moderna com foco em Dark Mode e responsividade.
- **JavaScript (Vanilla)**: Lógica do jogo, manipulação de DOM e métodos de Array (como `.join()`).
- **FontAwesome**: Ícones para redes sociais e interface.

## 🧠 Conceitos Aplicados
Este projeto foi desenvolvido como parte dos estudos de Algoritmos na **SPTech School**, aplicando:
- Variáveis globais e escopo de função.
- **Vetores (Arrays)** para armazenamento de estados.
- **Estruturas Condicionais** (`if/else if/else`) para validação de jogadas.
- **Métodos de String** como `.toUpperCase()`.
- **Manipulação de DOM** (`innerHTML`, `.value`, `.focus()`).

## 🎨 Preview da Interface
O projeto conta com uma interface moderna, inspirada em editores de código, com:
- Botões com efeitos de *hover* e transições.
- Campo de entrada com foco automático.
